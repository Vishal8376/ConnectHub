Glaze testing with regional basalt wash — notes on shrinkage and melt behavior

Spent the past ten days crushing raw volcanic basalt harvested from the river terrace. Mixed 4 test batches with 15% wood ash flux and applied onto high-iron stoneware tiles. Batch C produced this captivating olive-bronze microcrystalline skin during reduction at Cone 10. Shrinkage remained within 11.8%.
